# Hucha de Marc

App personal de ahorro: apunta lo que cobras en cada empresa y repártelo en huchas.

- Funciona en el navegador y se puede instalar en el móvil ("Añadir a pantalla de inicio").
- Los datos se guardan **solo en el dispositivo** donde la usas (nada se sube a GitHub ni a ningún servidor).
- Protegida con contraseña. Usa "Copia de seguridad" para descargar o cargar tus datos.
